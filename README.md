# TG WS Proxy Android

Android-форк TG WS Proxy с локальным MTProto-прокси, WebSocket-транспортом, Cloudflare fallback и актуальной сетевой логикой Flowseal.

## Скачать

Готовые APK публикуются в разделе **Releases** этого репозитория.

Для большинства современных Android-устройств подходит сборка **ARM64**. Также публикуются **ARM32** и **Universal** варианты.

## v1.3.0

- обновлён WS pool;
- добавлены refill/backoff и ротация соединений;
- добавлен fronting-first и fallback при timeout/reset;
- добавлен Cloudflare Worker fallback;
- Worker-домены настраиваются в приложении;
- LeakCanary удалён из пользовательских APK, поэтому отдельное приложение **Leaks** больше не появляется;
- добавлена автоматическая CI-сборка APK.

> Cloudflare Worker пока считается экспериментальной функцией и требует дополнительной проверки на реальных сетях.
